## 0.1.0 历史记录

## 已实现的边界

手机只控制 Context Relay 管理器里的任务。它通过固定证书的 HTTPS 连接同一台 Windows 管理器，由原来的单一 Worker 操作 Manager；不远程开放原生 RPC，不修改或接管仍在官方 Desktop 中运行的聊天。

远程功能默认关闭。一次性配对信息有效五分钟，设备可撤销。请求先在手机保存身份再发送，电脑保存幂等回执；结果未知不自动重发。撤销或关闭在本地请求入队前关闭权限入口，阻止尚未派发的命令；已进入 Manager 的操作须另外暂停和核对。

## 可复现检查

在仓库根目录执行：

```powershell
python -m unittest discover -s tests -q
python -m unittest discover -s skills/context-handoff/tests -q
python -m unittest -q test_install.py
.\mobile\Test-PhoneFirewall.ps1
```

Android 构建命令与工具要求见[构建说明](../mobile/android/README.md)。构建包含 47 条主机 JVM 断言、APK 签名和权限检查；这里只声明 `INTERNET` 权限。凭据使用 Android Keystore 密封，禁用备份、明文流量和界面截屏。

检查重点包括重复请求、修改内容却复用编号、过期状态、审批详情不足、换连接后失效审批、撤销、重启后未知结果、RPC 超时、慢 Manager 时仍可查询回执，以及没有 TLS 握手的连接不能阻塞正常访问或关闭。

防火墙辅助脚本单独通过解析和 13 个规则归属检查；修改过的程序、地址、端口、方向、协议和权限属性均被拒绝覆盖。脚本只处理具体程序、具体本机 IPv4、单一 TCP 端口和私有来源范围。

## 仍需真实设备验收

- Android 安装、系统版本、输入法、屏幕及后台恢复：尚未连接用户手机，未验收。
- 实际手机到电脑的局域网连接：模拟器的 `10.0.2.2` 路径不能替代真实 Wi-Fi 验收。
- 手机移动数据与异地私有网络：尚未完成双方私有网络登录和实际连通验证。
- 完整原生 AI 简报 → 采用 → 工作 → 独立审核 → 返工：历史原生探测存在证据格式失败；合成流程通过不消除这个缺口。
- 当前安装包使用仓库外的本地测试签名，不是应用商店审核或正式发布签名。更新须保留同一签名身份。

电脑需保持开机、网络连通和管理器运行；关闭手机 App 不代表暂停电脑任务。私钥与操作账本依赖当前用户私有状态目录，不应放入共享目录或源码仓库。上述保护不能对抗已被控制的电脑、手机或同账号进程。
