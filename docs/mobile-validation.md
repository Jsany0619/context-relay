## 0.2.3 预算原因与失败回执提示

- 预算的累计计算和限制保持不变。拒绝启动时指出触发的是时间或 Token、累计值及上限；自动触发暂停时记录原因和事件，并明确“已请求暂停”，不在原生停止确认前声称已经停止。
- 手机首屏直接显示确定失败或提交拒绝的原因，后台成功刷新不能把它覆盖为普通连接提示。未知、进行中、成功回执的判断不变；没有清除未确认请求或自动重发，也没有自动增加任务额度。
- 新增 Manager 假时钟回归先失败再通过：达到累计时间后只请求一次中断，终态保留原因，再启动被拒且没有新增原生调用。Manager 和设置 49 项、网关和电脑界面 54 项通过；修正文案后该针对性用例再次通过，不重复计入总数。本次没有重复 Python 全套。
- Android 失败提示的新增检查先在第 76 条断言失败，修复后 129 项 JVM 检查通过；API 35 Java 编译、v2/v3 签名和仅 `INTERNET` 权限检查通过。APK versionCode `5` / versionName `0.2.3`，签名身份保持不变，SHA-256：`cadd0c08d6e71b115751ceef876d57148e215c3aa1395b6822853136d7ee1286`。
- 本版没有 Android 运行或实体手机验收；这些检查不证明手机已收到新的模型回复。时间额度调整需要用户明确决定，旧失败请求不自动重发。更新电脑代码后须在任务收束时重新启动管理器才会加载新提示。

## 0.2.1 原聊天接续与原文阅读

本节分别记录接口与自动化证据；Android 新原文界面、实体手机和 Desktop 同步不由这些结果代替。

- 电脑明确选择“连接原聊天”，确认原聊天及同项目操作停止，并重新选择只读 / 项目可写权限。接续使用独立 App Server 的 `thread/resume`、保留原 thread ID；不代表 Desktop 宿主实时镜像或输入框同步，不继承旧审批。
- 仅直接连接模式原样传递手机本次输入，保留前后空格和换行，不添加管理器提示词；历史导入仍须按简报流程采用后工作。未知结果不重试。
- 原文文字按每页最多 6,000 字符 / 8 条分页，长消息分段；附件和工具详情标明未包含。本版 `thread/read` 上限 16 MiB，超限或只有摘要明确拒绝，不静默改用摘要。
- 原文 GET 核验固定证书 HTTPS、设备身份和已选任务范围；正文不进入网关操作回执日志或手机 Vault。显示原文是用户明确选择的功能，私有正文不得进入公开仓库或本记录。

- Python 全套 287 项通过；其后新增一项“发送保留空格、关闭原文窗口后迟到回包不得重新弹窗”回归单独通过。包括直接连接使用同 ID、无输出 schema / 简报 / 包装文本、禁止直接模式换聊和生成式返工、原文分页重组逐字一致、历史变化拒绝、只读设备授权、读取中撤销和内部简报不进入回复区。
- 真实 Codex 隔离探针：两次短模型调用均 `completed`，不重试；第二个客户端恢复同 ID，用户前后空格、换行和助手回复逐字一致，第二轮保留并正确引用首轮内容。创建及恢复均为 `readOnly` / `on-request`，外部 MCP 禁用。探针使用测试线程，不能代替真实 Desktop 聊天并发控制或窗口同步验收。
- 真实 Windows 管理器在核对原生分析终态后正常升级；通过管理器的只读恢复接口退出旧候选错误状态，没有重跑工作轮次。原文读取成功、设备授权保留、匿名 HTTPS 请求仍返回 401。未向真实项目自动发送执行指令。
- 尚未验证：新版原文界面在实体手机上的交互、Desktop 窗口实时同步、移动网络和长期运行。使用步骤见[手机指南](mobile.md)。

## 0.1.0 历史记录

## 已实现的边界

0.1.0 手机只控制 Context Relay 管理器里的任务。它通过固定证书的 HTTPS 连接同一台 Windows 管理器，由原来的单一 Worker 操作 Manager；不远程开放原生 RPC，不修改或接管仍在官方 Desktop 中运行的聊天。这项历史边界不作为新版“连接原聊天”的验证结论；新版也不保证 Desktop 宿主实时同步。

远程功能默认关闭。一次性配对信息有效五分钟，设备可撤销。请求先在手机保存身份再发送，电脑保存幂等回执；结果未知不自动重发。撤销或关闭在本地请求入队前关闭权限入口，阻止尚未派发的命令；已进入 Manager 的操作须另外暂停和核对。

## 可复现检查

在仓库根目录执行：

```powershell
python -m unittest discover -s tests -q
python -m unittest discover -s skills/context-handoff/tests -q
python -m unittest -q test_install.py
.\mobile\Test-PhoneFirewall.ps1
```

Android 构建命令与工具要求见[构建说明](../mobile/android/README.md)。构建包含 47 条主机 JVM 断言、APK 签名和权限检查；这里只声明 `INTERNET` 权限。凭据使用 Android Keystore 密封，禁用备份、明文流量和界面截屏。

检查重点包括重复请求、修改内容却复用编号、过期状态、审批详情不足、换连接后失效审批、撤销、重启后未知结果、RPC 超时、慢 Manager 时仍可查询回执，以及没有 TLS 握手的连接不能阻塞正常访问或关闭。

防火墙辅助脚本单独通过解析和 13 个规则归属检查；修改过的程序、地址、端口、方向、协议和权限属性均被拒绝覆盖。脚本只处理具体程序、具体本机 IPv4、单一 TCP 端口和私有来源范围。
