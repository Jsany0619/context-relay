# 聊天界面布局

本轮采用 A 手机聊天、B 电脑双栏。任务看板属于后续候选，未列入本轮交付。

- 电脑：左侧是任务名称、摘要、状态和更新时间；右侧是当前任务标题、连续对话和底部输入区。新建、导入、筛选和其他管理操作保留可访问入口，不挤占阅读区。
- 对话使用随内容宽度收缩的圆角气泡，用户靠右、Codex 靠左，气泡内文字左对齐。保留原文的空白、换行、选字与复制；长消息自动换行，变化前的消息不因追加新消息重建。按钮、搜索、筛选、更多菜单入口和输入区使用统一可见的圆角。
- 手机：顶部是返回、任务名和更多；中间是可选择文字的消息列表；底部多行输入与发送按钮在同一圆角区域。用户消息靠右，Codex 消息左对齐。软键盘开启后输入与发送仍可达。
- 普通状态用紧凑文字表达；权限模式、异常、结果未知及待审批事项不能用“在线”或“完成”的装饰状态代替。具体信息以实际回执为准。
- 沿用经典蓝和淡绿青两套配色、字号和间距选项。淡绿青采用白色正文、浅中性侧栏、深青色主操作；以留白和字号建立层次，不把整页染绿。
- 原话接续任务从现有原生文字读取接口加载对话；明确页码与附件／工具详情缺口。旧请求不能显示到新选中的任务，失败不能用摘要冒充原文。只读恢复库仅显示备份内容，不连接 Codex。

## 字体、入口与刷新

- Windows 标准界面使用 10pt 控件、11pt 聊天正文、15pt 侧栏标题和 13pt 任务标题；大字保留独立选项。跟随系统 DPI，不修改用户的系统缩放。正文、任务名称、辅助信息各有层级，不把所有文字都加粗放大。
- Windows 在创建首个窗口前启用系统 DPI 感知，避免低分辨率画面被系统放大后发糊；保留已有的 DPI 模式。本机 125% 缩放已经验证，跨不同缩放比例的显示器移动窗口不在本次验证范围内。
- 全局设置固定在侧栏底部，按通用、手机连接和数据诊断归类；当前任务的操作留在任务菜单。复用现有功能，不显示尚未实现的账号、语音、文件上传或云同步按钮。
- 手机标题右侧的小箭头展开或收起连接说明、地址、更新时间和任务长资料。默认收起；展开只改变说明区，不重新创建聊天或清空草稿。离线、失败、只读及待核对操作保留简短提示和实际处理入口。
- 手机非聊天区域的敏感资料保持遮罩，闭眼按钮单独发起系统身份验证。验证只允许查看当前资料，退出查看、换页或退到后台重新隐藏；配对秘密和访问凭据不提供明文查看，聊天原文与输入草稿不改写。
- 外观设置保留即时预览、取消恢复和明确保存；两套主题用可见示意辅助选择。电脑和手机各自保存偏好，不把显示设置混入任务权限或预算。
- 轮询只在主操作变化时调整按钮布局；数据未变时不重建对话。测试窗口必须透明或隐藏，不能在用户桌面反复弹出或强行获取焦点。

参考成熟聊天软件的分层导航与分组设置，不复制其品牌、个人资料或未实现的服务。手机仍以当前任务的阅读、输入、返回与必要处理为主；系统字体优先保证中文、英文和代码清晰。

验收应分别记录：源码和自动化检查、实际控件与布局、手机真机交互、用户对外观的认可。使用示例任务的真实应用渲染，可以证明布局；不能证明真实任务推进或网络长期稳定。网页原型、主机断言和安装成功均不能代替最终应用界面验收。
