# 手机安全与聊天体验升级

2026-10-02。依据用户明确要求实施，复用现有 Windows Manager、HTTPS 网关与原生 Android App。

## 验收范围

- 手机启动/返回前台通过系统设备凭据验证；未配置安全锁时拒绝连接与操作。锁定期间不得发送命令或显示敏感结果。
- 电脑配对时明确选择任务及只读/控制权限，默认不授权任务；设备令牌七天到期。旧版无权限范围的设备失效。任务查询、命令、回执和实际派发均核验权限。
- Windows TLS 私钥与签名口令用当前用户 DPAPI 保护，私有文件权限；不声称整个任务库加密，不声称抵抗同用户恶意程序或管理员。
- Android 发布构建保留原证书身份以便覆盖安装，将测试口令迁移为受保护随机口令；不发布私钥，不声称获得应用商店认证。
- 手机任务详情采用消息序列、顶部状态、固定底部输入，持续刷新当前结果；保留草稿/滚动位置。确定回执自动归档，未知回执不重试。安全过滤后的完整消息更新，不把任意 token 碎片推送为已核验结果。
- 管理器保存有界对话记录，导入的历史明确标为历史参考；保留工作结果，不混入内部交接/审核 JSON。代码块可读、文本可选，审批仍保留当前完整证据。
- 导入仍在电脑选择已有 Codex 聊天，原执行者先停止；不通过导入同时接管原桌面聊天。新任务须再授予手机访问权。
- 异地使用已登录的 Tailscale 私有网络并继续使用证书固定的 HTTPS；不开放公网端口，不自动购买服务，不绕过用户登录或 Android VPN 确认。

## 分工与验证

1. 网关与电脑配对 UI：到期/越权/旧权限迁移/在队列中撤销的回归测试；真实隔离 HTTPS。
2. Android：系统锁生命周期、聊天页面、已知/未知回执恢复；主机检查与实际模拟器交互。
3. Windows 与构建：DPAPI 往返、篡改拒绝、临时明文清理、签名升级一致性。
4. Manager：消息去重、重启保留、未知结果核对、导入历史、秘密跨 delta 不落盘；网络说明与小型只读诊断工具。
5. 集成验收后构建 APK，核验签名及权限，发布清楚的升级说明。真实手机解锁、安装及移动网络测试需要用户在自己的设备上完成。

## 不能由本次代码消除的边界

没有软件能保证已被控制的手机/电脑安全，也不能保证模型判断、所有运营商网络或永不掉线。读取任务资料仍须遵守原始授权，模型请求仍使用相应云服务。手机提供 Context Relay 实际支持的任务对话、审核与控制，不假装拥有 ChatGPT 的全部语音、图像、附件或云端工具能力。
